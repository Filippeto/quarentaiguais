# 40iguais

Apresentação interativa de identidade visual. Site estático: HTML, CSS e JavaScript, sem instalação ou compilação.

## Enviar pelo site do GitHub

1. Extraia o ZIP no seu computador.
2. Abra o repositório no GitHub e escolha Add file > Upload files.
3. Arraste todo o CONTEÚDO desta pasta, incluindo a pasta assets, para a área de upload. Preserve as subpastas. O index.html precisa ficar na raiz do repositório.
4. Confirme em Commit changes.

Não envie o ZIP como arquivo único: envie os arquivos extraídos.

Documentação: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository

## Usar

Abra index.html no navegador. O mini game funciona com mouse, toque ou setas do teclado com a quadra em foco. Espaço pausa. A galeria aceita setas e Esc.

Este pacote inclui favicon, fontes locais, imagens utilizadas e todos os scripts necessários. As versões antigas e os utilitários locais de prévia e testes ficaram fora deste pacote.
